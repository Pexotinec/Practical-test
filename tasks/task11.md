Задача 11. API для списка задач

1. Операции и запросы

 Операция | Запрос 

 Создание задачи | `POST /api/tasks` 
 Получение списка задач | `GET /api/tasks` 
 Получение одной задачи | `GET /api/tasks/1` 
 Изменение статуса | `PATCH /api/tasks/1` 
 Удаление задачи | `DELETE /api/tasks/1` 

2. Примеры запросов и ответов

Создание задачи

Запрос: `POST /api/tasks`

{
  "title": "Изучить SQL",
  "description": "Решить практические задания"
}


Ответ: `201 Created`

{
  "id": 1,
  "title": "Изучить SQL",
  "status": "pending"
}

Изменение статуса

Запрос: `PATCH /api/tasks/1`

{
  "status": "completed"
}


Ответ: `200 OK`

Удаление задачи

Запрос: `DELETE /api/tasks/1`

Ответ: `204 No Content`

3. Коды ошибок

- `400` — некорректные данные.
- `401` — пользователь не авторизован.
- `403` — недостаточно прав.
- `404` — задача не найдена.
- `500` — ошибка сервера.

4. Постраничная выдача

Запрос: `GET /api/tasks?page=1&limit=10`

- `page` — номер страницы.
- `limit` — количество задач на странице.
- `total` — общее количество задач.
